## E. 2026-10-25 全源码审核轮（修复记录 + 剩余 backlog）

四路并行审查（内核更新管线 / 代数与算法层 / 交互工具层 / 未提交 diff）报告约 30 项，逐条验证后修复如下（回归用例在 `conic-robustness.test.ts`、`review-fixes-round1.test.ts`、`review-fixes-round2-tools.test.ts`，共 27 个新用例）：

**正确性（原 A 类级）**
- 圆锥曲线属性命令幻影输出：`Focus/Vertex/Directrix/Axes` 对圆/抛物线在原点多出第二个"已定义"对象 → `apply()` 改为返回实际赋值个数，未定义输出不进构造不占标签。
- 退化判定尺度失效：`isConicDegenerate` 的 `mag³` 容差在圆心远离原点 ~215 单位后把普通圆误判退化（不可见、Focus 失效）；`analyzeConic` 分界阈值混入 `|F|` 同病 → 重写为平移不变判据（二次块降秩 + 中心系相对相消幅值）。
- 数值参数活依赖丢失：`Circle(A,r)`/`Rotate(A,t)`/`Dilate(A,s)` 的滑块被读成静态快照 → 三算法接受 `GeoNumeric` 活输入，序列化对称更新。
- **redo delete 误用 addElement**（审核第二轮发现）：删除 → 撤销 → 重做把元素重复加回构造 → 改为按 constIndex 逆序 removeElement。
- `RegularPolygon` 代数命令丢失顶点输出 → 存档重载多边形整体消失 → 全部输出随返回值登记。
- `AlgoPointInRegion` 拖拽不传播下游（不走隐藏参数的约束算法普遍问题）→ 拖拽路径补 `recomputeDependents`。
- 删除动画对象留僵尸 RAF 循环 → 删除级联退订动画 + loop 内"仍在构造中"防御剔除。
- 弧扫向三处解释不一致（WebGL 主后端在 ea<sa 时画到错误端点）→ 统一"从起点正向扫到终点"约定（渲染 / isOnPath / PointOnArc 拖拽夹取）。

**交互/状态机**
- polygon 工具中途退出误删用户既有点（无 undo、不可恢复）→ 只回收本工具新建的点。
- 两点工具第二次空白点击被吞（无法空白点两点）→ 已修。
- angle 工具顶点错在第三击 → GeoGebra ∠ABC 语义（第二击为顶点）。
- tangent 工具恒取"构造中最新一条"圆锥曲线 → 按点击命中、任意顺序。
- parabola 工具第二击强制造游离点、准线分支死代码 → 命中直线作准线，否则水平线回退。
- angle_bisector 预览画的是垂线 → 与构造一致的 normalize(BA+BC)。
- 框选容差世界单位 5 → 5px；Ctrl+框选"并集"→ 成员取反；隐藏对象/导航未到对象不再进入框选、右键菜单、标签拖拽、平移预判。
- Snap 吸附不取最近点（取决于构造顺序）→ 全量扫描取最小。
- 数值浮层外点取消先于画布守卫 → 画布内 pointerdown 交回守卫消费（单步工具不再立刻重弹框）。
- 重命名 undo/redo 不回滚复选框 `linkedLabels` → 对称改写。
- 滑块/复选框 UI 元素不入 undo（删内核对象留画布残影）→ 'add'/'delete' 命令携带 `uiElements`，undo/redo 同步增删。
- checkbox 联动点击无标签对象静默忽略 → 自动补标签。

**性能与健壮性**
- 动画 tick 依赖链双算（挂 Locus 时双倍采样）→ `withBatchedUpdates` 批末统一 flush；值未变化的帧不入队；loop 异常防护、迭代副本（play-once 不跳帧）；组件卸载停 RAF + 清 hoverRAF + 解除内核回调。
- 删除级联 `unregisterForwardDeps` 全 Map 扫描 O(N²) → 反向索引 `algoInputs`，退订 O(输入数)。
- `Kernel.flush` 单算法异常中断整批（pending 已清空，剩余永不重算）→ per-algo try/catch。
- undo move 全场重算后再增量重算一遍 → `withBatchedUpdates` + 新增 `Kernel.clearPendingUpdates()`。

重定义（Redefine）缺失、动态外观（条件显隐/动态颜色）缺失。回归用例在
`review-fixes-round3-dynamic.test.ts`（10 用例）。

### F2 剩余 backlog（按动态几何工作流影响排序）

1. **重定义（Redefine）缺失**（官方 `AlgebraProcessor.changeGeoElement` + `Construction.replace`：保标签保依赖者，自由点↔依赖点互换）——迭代建模工作流硬缺口，工作量 大。
2. **2D 拖拽的函数/参数曲线分支**（官方 `moveFunction` 平移表达式）。
3. **条件显隐 / 动态颜色**（官方 `setShowObjectCondition` / `getColorFunction`）——布尔滑块控显隐是 GeoGebra 动态课件核心表达。
4. **Attach/Detach 点工具**（官方 MODE_ATTACH_DETACH）。
5. **黎曼和族 Sum/LeftSum/UpperSum/LowerSum**（定积分直觉教学）。
6. **3D 依附点交互创建**（球面/柱面/多面体面上取点——`Region3D` 参数化，工作量大；3D 拾取也只认点，线/面/球选不中——拖拽主干已通，拾取是下一优先）。
7. **Trace 扩容**（直线/函数/圆锥/轨迹开 trace 静默无效；150 条上限 5 秒即逝；无整体清除入口）。
8. **Locus 质量**（固定 120 点无自适应加密/闭合判定；`Locus(Q, slider)` 驱动形式；轨迹上再取点需 GeoLocus 实现 Path）。
9. **画布滑块 widget 与内核脱节**（动画推进时 widget 不回写、min/max 固定 [0,100]、不入序列化——长期应按官方把 slider 下沉到渲染循环）。
10. **动态文本**（`"面积 = " + a` 实时标注——求值器需引入字符串值类型）。
11. **InputBox + 最小脚本命令**（SetValue/StartAnimation + 按钮绑定）。
12. **Sequence/Element/First/Last 列表命令**（正 n 边形族、多点迭代的基石）。
13. **曲面实体化渲染**（球/柱/锥经纬三角化 + Lambert 光照）、**2D 点拖入 3D 自动升级 GeoPoint3D**。
14. **点工具路径吸附预览**（幽灵点：hover 在路径上显示约束落点）。
15. **IntegralBetween + 阴影区域、Tangent(P, f)、Extremum/Root/FitLine 工具版、Function Inspector、Relation 对话框**（一批中小项）。

> 注：原 backlog 的「3D 拖拽装饰（高度虚线段）」已随 3D 拖拽主干实现（buildScene dragHint）。

2D 工具覆盖度评估（对照官方 146 个 Cmd*.java 中动态几何教学常用集）：交互工具约 85%，命令层约 75%，函数分析延伸与列表/脚本/动态绑定约 50%。
